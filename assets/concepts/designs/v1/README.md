## Typography and exports

The baseline retains Driver weight `700`, Dreamer weight `750` and letter spacing `-2`. Track Precision uses weight `700` for both words; Geometric GT uses `500` for both. Graphite Ember, Forest Gold and Burgundy Ivory use `700` for both. All five studies use letter spacing `-1`.

Every wordmark retains font size `66`, position `x="292"`, `y="152"` and `dx="10"` before Dreamer. Fonts remain live text using installed system families and the stated fallbacks; no font binaries are redistributed.

The five experimental PNG previews and the comparison sheet render their wordmarks from outlines of the selected installed fonts, so their typography remains visible without those fonts installed. The individual SVGs retain editable live text. The original official baseline is copied unchanged in both formats.

Each study includes a full-logo SVG and PNG plus an icon SVG and PNG. All individual canvases are transparent. Full-logo PNGs measure **1840 × 512**; icon PNGs measure **768 × 768**. The full-logo and icon SVG viewBoxes remain `0 0 920 256` and `0 0 256 256` respectively.

The official selection and historical logo rounds remain unchanged. These are design studies for review.
