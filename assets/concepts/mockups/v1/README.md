# Driver Dreamer website mockups — v1

Three desktop website concepts carry the selected straight thin wide official logo into a real landing-page composition. Each includes a header and menu, a Ferrari hero, one content section, and a footer. The UI uses the original navy `#07162F`, racing red `#E32636`, and white `#FFFFFF`, with pale gray surfaces where needed.

| 1 | Open Road | Avenir Next Regular / Bold | Spacious white split hero with a separate vehicle photograph and three garage tiles. | [PNG](01-open-road.png) | [SVG](01-open-road.svg) |
| 2 | Trackside | Futura Medium / Bold | An immersive circuit photograph with a navy reading overlay and strong geometric headings. | [PNG](02-trackside.png) | [SVG](02-trackside.svg) |
| 3 | Sunday Drive | Gill Sans Regular / SemiBold | Centered editorial introduction, a panoramic car hero, and a compact garage feature row. | [PNG](03-sunday-drive.png) | [SVG](03-sunday-drive.svg) |

The unchanged official logo appears in every header and footer. Website typography varies; the logo itself uses its original wordmark. Rounded Touring and Condensed GT, the two rejected v2 directions, are excluded.

Open [the comparison grid](04-comparison.png) to compare all three complete pages. Each full-page preview is 1440 × 1280 pixels. The comparison also has an [SVG source](04-comparison.svg).

The shared [hero artwork](media/hero-ferrari-458.png) depicts a red Ferrari 458 Italia coupe with a cream tan cabin and polished silver factory-style five-spoke wheels, under a blue sky beside green grass and a dark asphalt circuit. It was created using built-in image generation; the saved prompt and original generation location are in [prompts.md](prompts.md). The same scene keeps the layout comparison consistent.

`media/logo.png` is an unchanged copy of `assets/brand/logo.png`. The editable page SVGs reference the two files in `media/`; keep that folder alongside the SVGs. PNG exports include the artwork and the selected font faces. These are static design artifacts. Navigation labels and links describe the intended website structure.

The footer includes the current 2026 copyright, About, Terms, Contact, Privacy, and a linked [Piratechs](https://piratechs.com/) credit. Prior logo/design concepts and official brand assets remain preserved.
