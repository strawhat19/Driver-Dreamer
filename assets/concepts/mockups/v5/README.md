# Driver Dreamer website font concepts v5

This round carries forward the selected White Emotion compositions from v4 concepts 01 and 02. Six native SVG and PNG mockups compare three heading font pairs across the transparent sky header and red header. The Ferrari and cloud photograph, straight thin wide crest, layout and navy, red and white palette continue from that round.

## Typography

- **Signature GT:** white `CHASE THE` in Avenir Next Bold 700 at 105 px; red lowercase `feeling.` in Snell Roundhand Bold 700 at 108 px. The collection's red script line uses Snell Roundhand Bold at 52 px.
- **Brush Drive:** white `CHASE THE` in Futura Bold 700 at 112 px; red lowercase `feeling.` in Brush Script MT Italic 400 at 132 px. The collection's red script line uses Brush Script MT Italic at 52 px.
- **Grand Tour Editorial:** white mixed case `Chase the` in Baskerville Bold 700 at 136 px; red lowercase `feeling.` in Baskerville Italic 400 at 124 px. Collection headings use Baskerville Bold at 43 px, followed by a red Baskerville Italic line at 48 px.

All navigation, body copy and small interface labels use Futura Medium 500 or Bold 700. Script glyphs, including their swashes and descenders, stay entirely above the Ferrari. The palette remains deep navy `#07162F`, racing red `#E32636` and white `#FFFFFF`.
