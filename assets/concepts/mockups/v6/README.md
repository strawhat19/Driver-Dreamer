# Driver Dreamer white header navigation concepts v6

This round refines the selected **v5 number 1, Signature GT — Sky**, and **v5 number 3, Brush Drive — Sky**. Both new mockups retain their photograph, layout, interface, red footer and heading fonts, with a white header wordmark and white icon and text navigation over the sky.

| **1** | **Signature GT — White Navigation** | v5 number 1 | Avenir Next Bold 105 px + Snell Roundhand Bold 108 px | [01-signature-gt-white-navigation.svg](01-signature-gt-white-navigation.svg) |
| **2** | **Brush Drive — White Navigation** | v5 number 3 | Futura Bold 112 px + Brush Script MT Italic 132 px | [02-brush-drive-white-navigation.svg](02-brush-drive-white-navigation.svg) |

Choose **1** for the flowing Snell signature or **2** for the Brush Script accent. These are the new round's numbers; their selected v5 source numbers were **1 and 3**.

The header uses [logo-on-sky-white.svg](media/logo-on-sky-white.svg) and its [transparent PNG](media/logo-on-sky-white.png). Only the header's Driver Dreamer wordmark becomes entirely white. The official navy and red crest remains unchanged, with a transparent surrounding canvas and no backing plate. Discover, Collections, Journal, About and My Garage use white text with native compass, stacked cards, book, information and garage icons respectively.

The red footer retains its existing contextual logo: navy Driver and white Dreamer. The palette stays navy `#07162F`, red `#E32636` and white `#FFFFFF`. Collection accents remain Snell Roundhand Bold or Brush Script MT Italic at 52 px; smaller interface text remains Futura Medium 500 or Bold 700.

Each concept includes an editable SVG, a **1440 × 1440** full page PNG and a **1440 × 810** `-hero.png`. Compare them in [03-hero-comparison.png](03-hero-comparison.png) or [04-full-page-comparison.png](04-full-page-comparison.png); both have matching editable SVGs and use two columns in one row. [mockups.json](mockups.json) records the source selections, header assets, typography and output paths.

These are local SVG and PNG design assets. Source SVGs reference the actual system font families, and PNG exports use native font outlines prepared with temporary private font files. No font binaries are redistributed. Application code, official brand files and earlier rounds remain untouched; no application builds or tests were run.
