## Logo placement

There are no white carriers, background panels or shadows behind the logos. The transparent header uses an unchanged copy of the original official logo. On red backgrounds, a contextual transparent logo changes only the Dreamer wordmark fill from racing red to white. The original crest geometry, crest colors, Driver lettering and wordmark typography remain intact. This makes the wordmark readable on red without a backing panel.

Contextual files are in [media/logo-on-red.svg](media/logo-on-red.svg) and [media/logo-on-red.png](media/logo-on-red.png). Official files in `assets/brand/` remain preserved.

## Visual direction

The UI palette remains navy `#07162F`, racing red `#E32636` and white `#FFFFFF`. The UI font faces remain Futura Medium and Bold. Oversized type is positioned over open sky; supporting text and actions sit in the open left side of the image, and the vehicle rail is below the car. The Ferrari hood, cream tan cabin and polished silver wheels remain visible.

Both page concepts include Discover, Collections, Journal, About and My Garage navigation; one collection section; and red footers with About, Terms, Contact, Privacy, current 2026 copyright and linked [Piratechs](https://piratechs.com/) credit. These are static visual concepts, with editable SVG interface elements.

The photograph is the unchanged generated v1 asset, copied into this version's `media/` folder. Its original image-generation prompt is preserved in [v1/prompts.md](../v1/prompts.md). This round uses native vector layout and typography; no new image generation was needed. Keep `media/` beside the editable SVGs.
