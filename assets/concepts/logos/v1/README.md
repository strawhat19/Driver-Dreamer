# Driver Dreamer logo concepts — V1

First logo round for **Driver Dreamer**, an app and database of luxury, sports and exotic vehicles.

## Concepts

### Apex Double D

A compact DD monogram pairs deep navy and red. White lane accents make the two initials read as parallel racetrack forms. Suited to an app icon, avatar or vehicle watermark.

[Full logo](01-apex-double-d.svg) · [Icon](01-apex-double-d-icon.svg)

### Grand Tourer Crest

A softened navy crest combines an original front-facing exotic-car silhouette with red automotive accents. Suited to a collection badge, membership identity or app icon.

[Full logo](02-grand-tourer-crest.svg) · [Icon](02-grand-tourer-crest-icon.svg)

### Vehicle Index

Layered vehicle cards connect the automotive identity to the database. A low sports-car silhouette and red indexing accent make the catalog idea visible. Suited to the app icon, search identity and collection views.

[Full logo](03-vehicle-index.svg) · [Icon](03-vehicle-index-icon.svg)

## Asset notes

- Individual SVGs have transparent surrounding canvases. Solid fields inside badges/cards are part of the logo.
- PNG previews use white backgrounds; the comparison also shows inverse marks on deep navy.
- Symbols use editable vector paths. Wordmarks use live text with Avenir Next, Inter and Arial fallbacks; outline the chosen typeface when preparing production artwork.
- These are original concept directions, with no vehicle manufacturer badges or specific car model drawings.
- Created as native SVG artwork following `Logo_Mockup_Guides.md`. No application code was changed.
- Future rounds should use `assets/concepts/logos/v2/`, `v3/` and onward, preserving this first round.
