# Driver Dreamer official brand assets

**Grand Tourer — Straight Thin Wide** is the selected official logo. These four assets are unchanged copies of `assets/concepts/logos/v7/02-grand-tourer-straight-thin-wide` and its icon companion; the original concept files remain in place.

- [logo.svg](logo.svg) — editable full logo, `0 0 920 256` viewBox.
- [logo-icon.svg](logo-icon.svg) — editable crest icon, `0 0 256 256` viewBox.
- [logo.png](logo.png) — transparent full logo, 1840 × 512.
- [logo-icon.png](logo-icon.png) — transparent crest icon, 768 × 768.
- [brand.json](brand.json) — official source, canonical paths, palette and typography.

The original palette uses deep navy `#07162F` for the shield, car details and Driver text; racing red `#E32636` for the crown, straight thought trail and Dreamer text; and white `#FFFFFF` for the car silhouette.

The live SVG wordmark retains the exact `Avenir Next, Inter, Arial, sans-serif` font stack, font size `66`, Driver weight `700`, Dreamer weight `750` and letter spacing `-2`. Its displayed typeface follows that fallback order. Both words, their placement and the crest geometry remain as selected.

The official baseline is kept here. Alternative fonts and colors belong in `assets/concepts/designs/` until selected.
